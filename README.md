# Hydz.in — building in public

[Hydz.in](https://hydz.in) is an AI automation + go-to-market advisory practice based in Hyderabad, India. We build practical AI tooling — websites, chatbots, booking systems, review management — for local small and mid-size businesses (SMEs) that don't have an in-house tech team.

This repo is a running log of what we're actively building. It's a curated, public-safe view — client details, pricing, and internal playbooks stay private, but the shape of the work doesn't.
